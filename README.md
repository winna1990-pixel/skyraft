# Sky Raft

Лети на плоту сквозь облака. Собирай дерево и верёвку, крафти парус, переживи шторм и птиц.

2D side-view: крафт на летающем плоту (выживание в небе).
Управление: WASD — движение, Space — hop, E — craft, F — Hook.

Страница на itch.io: https://winna1990.itch.io/sky-raft

Как играть: скачай exe из раздела Releases и запусти (Windows).

Игра сделана в развлекательных целях. Это копия оригинала (фанатская версия), не официальный продукт.
